# مركز دراسات السلام والتنمية – لوحة الإدارة

## تشغيل المشروع
```bash
npm install
npm start
```
ثم افتح `/admin` للدخول إلى لوحة التحكم.

## بيانات الدخول الأولية
- اسم المستخدم: `admin`
- كلمة المرور: `Peace@2026`

غيّر كلمة المرور من تبويب «الحساب» بعد أول دخول.

## وظائف لوحة التحكم
- إضافة وتعديل وحذف الأخبار.
- إضافة وتعديل وحذف البرامج.
- إدارة شريط الإعلانات المتحرك.
- إضافة وتعديل وحذف صور الواجهة الرئيسية مع المصدر والترخيص.
- رفع ملفات PDF وWord وExcel وPowerPoint والصور حتى 15MB.
- إدارة المستندات والملفات.
- تعديل محتوى قسم «عن المركز».
- تغيير اسم المستخدم وكلمة المرور.

## ملاحظة للنشر على Render
هذا الإصدار يستخدم ملفات JSON ومجلد `uploads` على الخادم. على الاستضافة التي لا توفر تخزينًا دائمًا قد تضيع التعديلات والملفات عند إعادة تشغيل الخدمة. للاستخدام المؤسسي الدائم يُفضّل ربط البيانات والتخزين بـ Supabase أو تخزين دائم في Render.
